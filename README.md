# Iran Network Monitor · پایش شبکه ایران

**English** · [فارسی](#فارسی)

Telegram bot [@inmapp](https://t.me/inmapp) that watches the health of Iranian networks and hosting providers from outside Iran, measures real bandwidth with iperf3, and publishes clear visual reports.

- 📢 Channel: https://t.me/IranNetworkMonitoring
- 🤖 Bot: https://t.me/inmapp
- 🤝 Sponsors / add your hosting: Telegram **@aqabolbol**

## Features
- 🧭 BGP maps and route intelligence, plus a check for any IP
- 📡 Monitoring of operators, ISPs, data centres and hostings
- 🚀 Real iperf3 speed tests every day at 12:00, 20:00 and 23:00 (Tehran), with peak-hour drops highlighted
- 📊 Weekly report ranking hostings by speed, stability and disruptions
